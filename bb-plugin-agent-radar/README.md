# 🛰️ Agent Radar (Activity HUD Plugin for Blackbox)

Плагин для визуализации активности искусственного интеллекта (Antigravity / Blackbox) в реальном времени.

Решает проблему неопределенности: **«Что делает агент прямо сейчас?», «Завис ли он?» и «Когда можно отправлять новое сообщение?»**.

---

## ✨ Возможности

1. **Плавающий HUD-индикатор (`appOverlay`)**:
   - 🟢 **`ИИ СВОБОДЕН (МОЖНО ПИСАТЬ)`** — яркий зеленый пульсирующий бейдж, когда ассистент закончил формулировать ответ и ожидает вас.
   - ⛔ **`ИИ РАБОТАЕТ (НЕ ПИШИТЕ)`** — предупреждающий янтарный индикатор с таймером выполнения, названием запущенной команды и кратким описанием шага (e.g., `⚡ run_command: powershell ...`, `📝 edit_file`).
2. **Сегмент над полем ввода (`threadContextSegment`)**:
   - Индикатор монтируется прямо над строкой ввода сообщения (`Ask for a follow-up`), показывая текущее состояние непосредственно перед отправкой.
3. **Звуковое оповещение (Chime)**:
   - Автоматический мягкий двухтоновый перезвон (Web Audio API) в момент перехода ИИ из режима «Занят» в режим «Свободен», чтобы вы знали о готовности ответа, даже переключившись в другое окно.
4. **Хронология шагов и детальная панель (`navPanel` / `tab`)**:
   - Полноэкранная консоль с фильтрами, временем выполнения каждого инструмента, расходом токенов и моделью.
5. **CLI-команда**:
   ```bash
   bb radar status
   ```

---

## 🛠️ Архитектура

- **Backend (`server.ts`)**: Отслеживает активность и парсит хвост логов `transcript.jsonl` в каталоге `.gemini/antigravity-cli/brain/<conversation-id>/`. Точно определяет фазы генерации, вызовы системных инструментов и завершение ходов.
- **Frontend (`app.tsx`)**: React + Tailwind HUD с полингом статуса каждые 1.5 сек.

```bash

# Установка

```
